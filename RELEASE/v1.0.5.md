# v1.0.5 — CVE patch: github.com/go-jose/go-jose/v4, plus a dependency/toolchain bump

Status: **Shipped.**

## What happened

A Trivy scan flagged a vulnerable transitive dependency:

| Module | CVE | Severity | Installed | Fixed in |
| :--- | :--- | :--- | :--- | :--- |
| `github.com/go-jose/go-jose/v4` (indirect) | CVE-2026-116587 | HIGH | v4.1.4 | 4.1.6 |

## Fix

- `go get github.com/go-jose/go-jose/v4@v4.1.6`.
- Also bumped every direct dependency to its latest release (arrow-go v18.8.0, iceberg-go v0.7.0, prometheus v0.315.1, client_golang v1.25.0, client_model v0.6.3, common v0.73.1, x/crypto v0.58.0, x/sys v0.49.0, x/term v0.47.0, protobuf v1.36.12) and Go 1.27.2 -> 1.27.3 (`go.mod`, `Dockerfile`, `ci.yml`, `release.yml`). No circa code changed.
- Verified locally: `trivy fs --scanners vuln --severity CRITICAL,HIGH .` reports 0 vulnerabilities; `go build ./...`, `go vet ./...`, `go test ./... -race` all pass.
