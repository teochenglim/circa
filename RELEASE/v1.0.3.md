# v1.0.3 — CVE patch: golang.org/x/net, Go toolchain 1.27.2

Status: **Shipped.**

## What happened

A Trivy scan flagged a vulnerable transitive dependency:

| Module | CVE | Severity | Installed | Fixed in |
| :--- | :--- | :--- | :--- | :--- |
| `golang.org/x/net` (indirect) | CVE-2026-78669 | HIGH | v0.58.0 | 0.60.0 |

## Fix

- `go get golang.org/x/net@v0.60.0` + `go mod tidy` — also pulled `golang.org/x/crypto` v0.57.0, `x/sync` v0.23.0, `x/sys` v0.48.0, `x/term` v0.46.0, `x/text` v0.42.0 as required by `x/net` v0.60.0.
- Go toolchain bumped to **1.27.2**: `go.mod`'s `go` directive, `Dockerfile` (`golang:1.27.2-alpine`), and `GO_VERSION` in `.github/workflows/ci.yml` / `release.yml`.
- No circa code changed; dependency/toolchain-only patch release, same shape as [v1.0.2](v1.0.2.md).
- Verified locally: `trivy fs --scanners vuln --severity CRITICAL,HIGH .` reports 0 vulnerabilities; `go build ./...`, `go vet ./...`, `go test ./... -race` all pass.
