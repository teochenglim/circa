# v1.0.1 — CVE-2026-33186 (google.golang.org/grpc)

Status: **Shipped.**

## What happened

The scheduled Trivy security scan (`.github/workflows/security.yml`) started failing on both the filesystem scan and the Docker image scan: `google.golang.org/grpc v1.81.1`, an indirect dependency pulled in via `github.com/prometheus/prometheus`, carries a HIGH-severity CVE (CVE-2026-33186 / GHSA-hrxh-6v49-42gf — xDS RBAC and HTTP/2 vulnerabilities), fixed in `1.82.1`.

## Fix

- `go get google.golang.org/grpc@v1.82.1` + `go mod tidy` — bumps the transitive dependency to the patched version. No circa code changed; this is a dependency-only patch release.
- Verified locally before pushing: `trivy fs --scanners vuln --severity CRITICAL,HIGH .` and `trivy image` against the locally built Docker image both report 0 vulnerabilities post-bump (previously 1 HIGH each, same finding). `go build ./...`, `go vet ./...`, and `go test ./... -race -cover` all pass.
